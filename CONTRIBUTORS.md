## How to Get Listed

If you contribute code, documentation, bug reports, or ideas:

1. Submit a PR or open an issue
2. Include your name and GitHub handle
3. We'll add you to this list!

## Contribution Types

- 💻 **Code**: Bug fixes, features, refactoring
- 📚 **Documentation**: README updates, guides, tutorials
- 🐛 **Bug Reports**: Issue identification and reproduction steps
- 💡 **Ideas**: Feature suggestions and improvements
- 🎨 **Design**: UI/UX improvements and visual enhancements
- 📝 **Translations**: Multi-language support
